HOW_IT_WORKS

6-Step Agent Commerce Flow

Every AISLE purchase follows a strict, auditable protocol. Nothing gets charged without passing through the Policy Engine first.

01
AGENT_TOKEN
Agent requests an identity token with encoded budget limits and category constraints. Cryptographically signed.
02
STORE_DISCOVER
Agent queries /v1/stores to find AI-enabled merchants. Gets machine-readable manifest with policies.
03
CATALOG_BROWSE
Structured JSON catalog — no HTML scraping, no captchas. Filter by category, price, availability.
04
POLICY_ENGINE
8-rule safety evaluator runs before any payment. Checks budget, velocity, categories, merchant kill-switch.
05
RAZORPAY_ORDER
Approved carts trigger Razorpay order creation via API with exponential-backoff retry logic.
06
AUDIT_TRACE
Every decision is logged with an AI-generated reasoning trace. Immutable, append-only audit log.
FEATURES

Built for the Agentic Era

AISLE isn't a chatbot integration. It's infrastructure — the missing protocol layer between AI agents and commerce systems.

🛡️
POLICY_ENGINE
8-rule safety evaluator: budget caps, velocity limits, category blocks, daily GMV caps, kill-switch. Runs in <5ms before every Razorpay call.
🧠
AI_REASONING_TRACE
Groq-powered LLM generates a natural language explanation of every purchase decision. Why did the agent pick this product? You'll always know.
🪪
AGENT_IDENTITY_TOKEN
JWT-based cryptographic identity for agents. Encodes budget, categories, TTL, and owner email. Agents can't forge their constraints.
📋
IMMUTABLE_AUDIT_LOG
Append-only Postgres table. Every API call logged with input, output, policy result, reasoning trace, and duration. Full compliance trail.
👁️
MERCHANT_DASHBOARD
Real-time feed of agent activity. Policy editor with live sliders. Analytics with 7-day GMV charts. Human review queue for high-value orders.
⚡
RAZORPAY_NATIVE
First-class Razorpay integration with exponential backoff, order tracking, and payment webhook support. Built for production, not demos.
